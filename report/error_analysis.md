# Error analysis (Phase 5)

Examples are taken from eval/text_results.json and eval/controlled_results.json, produced in this session. Personal names, places, phone numbers and e-mail addresses in dataset strings have been replaced with placeholders in angle brackets.

1. **Confirm shaming with non-standard grammar is missed (Yada, Mathur).** "No, I'll rather pay full price." and "No thanks. I don't like free things..." were not flagged. The hand-written pattern expects "I'd rather" or "I don't want/care/need"; ungrammatical or ironic variants fall outside it. Overall, 81 of 169 Mathur confirmshaming strings (0.48) were flagged.
2. **Scarcity wording outside the pattern list is missed (Yada, Mathur).** "4 items left", "1 in Stock" and "Limited Availability" were not flagged, because the pattern requires the form "only N left". Low-stock recall on Mathur was 0.71 (449 of 631).
3. **Countdown text is not a text signal (Yada, Mathur).** "Your order is reserved for 09:54 minutes!" was not flagged. The text scorer has no timer pattern by design; PatternGuard detects false urgency from timers by the reset-on-reload rule, which needs the live page and cannot be applied to a dataset string. Countdown Timer recall on Mathur was 0.27.
4. **Social proof has no CCPA category (Yada).** Strings of the form "<first name> in <city>, <country> purchased <product>" were not flagged; only 23 of 312 Yada Social Proof strings (0.07) were. The CCPA list has no social-proof category (report/mapping_mathur_to_ccpa.md), so these are outside the scope of the mapping rather than detector errors.
5. **Trick question paraphrase is missed (Mathur).** "Uncheck the box if you prefer not to receive email updates." was not flagged because the pattern expects "if you do not/don't". 0 of 9 Mathur trick-question strings were flagged.
6. **Hidden costs cannot be judged from one string (Mathur).** "Order Subtotal $<amount> Standard Delivery $<amount> Care & Handling $<amount> ..." was not flagged. Drip pricing depends on whether the charge was shown on an earlier step, which the extension tracks across steps of a live flow (rule `dripFee`) but which a single dataset string does not contain. The amounts are also in dollars, while the fee rule reads rupee amounts.
7. **Text-only configuration flags genuine scarcity claims (controlled test set).** With all alpha set to 0, "Only 2 left in stock." on demo/fair-checkout.html was reported as false urgency (1 false positive on each of the two loads), and on demo/dark-checkout.html the paragraph "Special price! Offer ends in 10:00" was reported instead of the timer element itself. In the combined configuration false urgency uses alpha = 1, so a timer is reported only when it restarts on reload.
8. **Rules-only configuration misses every wording-based pattern (controlled test set).** With all alpha set to 1, all 5 confirm-shaming elements and both trick-question elements were missed (7 false negatives), because these patterns have no structural signal.
